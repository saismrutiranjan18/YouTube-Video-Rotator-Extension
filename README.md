# 🔄 YouTube Video Rotator Extension

Rotate YouTube videos to any angle for comfortable viewing!

## ✨ Features

- **Quick Rotation**: 90°, 180°, 270° buttons
- **Fine Control**: Slider for any angle (0-360°)
- **Flip Options**: Horizontal and vertical flip
- **Keyboard Shortcuts**: 
  - `Ctrl+Alt+→`: Rotate 90° clockwise
  - `Ctrl+Alt+←`: Rotate 90° counter-clockwise
  - `Ctrl+Alt+↑`: Rotate 1° clockwise
  - `Ctrl+Alt+↓`: Rotate 1° counter-clockwise
  - `Ctrl+Alt+R`: Reset rotation

## 📱 Use Cases

- Watch videos while lying sideways in bed
- Fix wrongly uploaded/rotated videos
- Comfortable viewing for better neck/posture
- Portrait mode videos on landscape screens

## 🚀 Installation

1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" (top right)
4. Click "Load unpacked"
5. Select the extension folder

## 🎯 Usage

1. Open any YouTube video
2. Look for the rotation panel in the top-right corner
3. Use quick buttons or slider to rotate
4. Use flip buttons for mirroring
5. Click "−" to collapse the panel
